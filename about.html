About Trace
Trace is a cybersecurity project that teaches password safety and basic online protection in very simple words.
Our goal
Many people use weak passwords because nobody showed them a better way. Trace explains the risks and gives easy tools to fix them.
Built with
Plain HTML (only div tags), plain CSS and simple JavaScript. No libraries and no tracking. Everything runs in your browser.
What is inside
Home, Password checker, Password generator, Common threats, Safety tips, Quiz, and this About page.
Questions and answers
Is my password sent anywhere?
No. The checker runs fully in your browser and nothing is saved or sent. Still, never type your real password on websites you do not trust.
Can I use a generated password for a real account?
Yes. The generator uses your browser's secure random number tool. Save the password in a password manager so you do not lose it.
Is the time to crack exact?
No. It is a rough guess that only shows the idea: longer and more mixed passwords take much more time to break.
What is a password manager?
An app that stores all your passwords safely and fills them in for you. You only remember one strong master password.
